How good is it?

Every forecast slot is scored out of sample with walk-forward validation and only uses a model when it beats yesterday's value. Monthly values are seasonal averages; long-range daily forecasts are not attempted. Temperature and humidity are trained on Open-Meteo history, and the TMD value is the Thai Meteorological Department's own forecast. Details are in the model card.

Data: OpenAQ (Air4Thai reference stations), Open-Meteo (CC BY 4.0) and TMD.
